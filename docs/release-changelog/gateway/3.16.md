## Changes

* [Breaking changes, deprecations, and known issues](https://developer.konghq.com/gateway/breaking-changes/): 3.16.0.0 CEL engine migration from `cel-rust` to `cel-cpp` for conditional plugin execution, changing two behaviors (quote escape sequences now unescape correctly, and a missing map key such as `kong.ctx.shared[key]` now raises an error instead of returning `null`/`false`); known issue: the Entitlement Enforcement plugin's `config.credit_balance_required` and the `NO_CREDIT_AVAILABLE` reason code currently have no effect (credit balance enforcement isn't implemented yet).
