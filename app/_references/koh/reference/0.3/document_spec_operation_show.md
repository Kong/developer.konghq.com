---
title: document spec operation show
---

## Command Description

Show a single operation in a document spec

## Syntax

`document spec operation show [options]`

## Local Flags

- `--document <id|name>`: Document name or ID
- `--operation-id <operationId>`: Operation ID

## Global Flags

- `--project <path>`: Path to the Git Project directory (defaults to current directory)
- `--agent`: Output structured JSON for agent/LLM consumption
- `--verbose`: Show detailed logs
