## Command Description

Import an OpenAPI 3.x or Swagger 2.0 Specification as an Insomnia spec document

## Syntax

`import oas document [options] <file>`

## Local Flags

- `--target <id|name>`: Replace an existing document or create a document with this name

## Global Flags

- `--project <path>`: Path to the Git Project directory (defaults to current directory)
- `--agent`: Output structured JSON for agent/LLM consumption
- `--verbose`: Show detailed logs
