title: request list
---

## Command Description

List requests, optionally scoped to a collection

## Syntax

`request list [options]`

## Local Flags

- `--collection <id|name>`: Scope to a specific collection
- `--query <text>`: Case-insensitive query across request fields

## Global Flags

- `--project <path>`: Path to the Git Project directory (defaults to current directory)
- `--agent`: Output structured JSON for agent/LLM consumption
- `--verbose`: Show detailed logs
