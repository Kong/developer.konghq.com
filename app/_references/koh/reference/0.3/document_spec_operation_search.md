## Command Description

Search operations in a document spec

## Syntax

`document spec operation search [options]`

## Local Flags

- `--document <id|name>`: Document name or ID
- `--query <text>`: Case-insensitive query across operation fields
- `--filter-json <json>`: Structured JSON filter

## Global Flags

- `--project <path>`: Path to the Git Project directory (defaults to current directory)
- `--agent`: Output structured JSON for agent/LLM consumption
- `--verbose`: Show detailed logs
