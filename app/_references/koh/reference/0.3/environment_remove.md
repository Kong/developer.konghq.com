---
title: environment remove
---

## Command Description

Remove an environment, or a sub-environment when --environment is given

## Syntax

`environment remove [options] <id|name>`

## Local Flags

- `--environment <id|name>`: Parent environment containing the sub-environment to remove
- `--global`: Remove a global environment

## Global Flags

- `--project <path>`: Path to the Git Project directory (defaults to current directory)
- `--agent`: Output structured JSON for agent/LLM consumption
- `--verbose`: Show detailed logs
