title: import oas collection

## Command Description

Import an OpenAPI 3.x or Swagger 2.0 Specification as a collection

## Syntax

`import oas collection [options] <file>`

## Local Flags

- `--target <id|name>`: Merge into an existing collection or create a collection with this name

## Global Flags

- `--project <path>`: Path to the Git Project directory (defaults to current directory)
- `--agent`: Output structured JSON for agent/LLM consumption
- `--verbose`: Show detailed logs
