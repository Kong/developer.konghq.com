```
Manage public connection profiles and the global Claude integration.

Usage:
  agent-auth-cli profile <command>

Commands:
  create     Build and install a profile using OIDC discovery
  import     Install a complete profile from a file or HTTPS URL
  list       List installed profiles
  show       Show one installed profile's public configuration
  activate   Configure one or every detected agent CLI to use one profile
  cleanup    Remove settings still owned by agent-auth-cli
  delete     Remove one installed profile from this computer
```
