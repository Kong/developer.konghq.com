This tutorial uses [jq](https://jqlang.org/) to format JSON output. Install it:

{% navtabs "jq-install" %}
{% navtab "macOS" %}
```sh
brew install jq
```
{% endnavtab %}
{% navtab "Debian and Ubuntu" %}
```sh
sudo apt-get install jq
```
{% endnavtab %}
{% navtab "Windows" %}
```sh
winget install jqlang.jq
```
{% endnavtab %}
{% endnavtabs %}

For other installation methods, see the [jq download page](https://jqlang.org/download/).
