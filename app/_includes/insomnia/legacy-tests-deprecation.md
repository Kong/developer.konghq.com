> {% new_in 13.3 %} Legacy unit tests are hidden by default and are planned for deprecation in a future release.
>
> If you already use unit tests, {{ site.insomnia }} keeps them enabled for you. Otherwise, to follow this guide, go to **Preferences** > **General** and enable **Enable Legacy Tests**.
>
> For new work, use [pre-request and after-response scripts](/insomnia/scripts/) instead. Scripts are the recommended way to test APIs in {{ site.insomnia }}.
