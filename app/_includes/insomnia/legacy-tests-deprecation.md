{:.warning}
> {% new_in 13.3 %} Legacy unit tests are hidden by default and are planned for deprecation in a future release.
>
> If an API Collection already contains legacy unit tests, its **Tests** tab still appears automatically. Otherwise, to follow this guide, go to **Preferences** > **General** > **Application** and enable **Show legacy unit tests**, which shows the **Tests** tab on every API Collection.
>
> For new work, use [pre-request and after-response scripts](/insomnia/scripts/) instead. Scripts are the recommended way to test APIs in {{ site.insomnia }}.
