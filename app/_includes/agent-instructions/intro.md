## Konnect Deployments: Instructions for Agents - {{site.konnect_product_name}} MCP

If the {{site.konnect_product_name}} MCP server is connected, execute this guide with its tools
instead of the literal commands this guide shows.

- Discover the tools yourself.
- Call tools through code mode.
- Read before writing. List or get the current state of every entity you are about to change. Do not reuse an existing entity by `name`; create a new one with a different name.
- Read IDs from tool responses. Never reuse the guide's placeholder IDs or `$VAR=$(... | jq -r ".id")` shell patterns.
