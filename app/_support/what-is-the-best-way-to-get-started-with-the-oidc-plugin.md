## Getting started with the OIDC plugin

I would like to start using the OIDC plugin but the documentation is extensive and a little over-whelming, is there an easy step by step guide to getting started with OpenID Connect Plugin for Kong-EE?

There are a lot of options for the OIDC plugin and at first sight this can be confusing. Kong currently has two blog articles on this subject. You might like to start here with this blog which walks through a Keycloak setup and is quite basic. It will provide a solid foundation for a more advanced configuration later. This second tutorial discusses OIDC in greater depth and is a nice follow on to the previous post.
