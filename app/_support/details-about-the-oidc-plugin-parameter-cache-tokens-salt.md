faqs:
  - q: Does `cache_tokens_salt` affect the introspection response cache as well?
    a: |
      No, the introspection cache key does not use it.
  - q: Are there any recommendations for what the `cache_tokens_salt` value should be, in terms of length or character set?
    a: |
      No. By default, `cache_tokens_salt` is autogenerated. If you want multiple plugins to share the same cache, you can set it to anything, for example `wysiwyg` or the name of a realm, for example `my-realm`.
tldr:
  q: What does the OIDC plugin's `cache_tokens_salt` parameter affect, and what value should I use?
  a: |
    `cache_tokens_salt` does not affect the introspection response cache; it only applies to the token cache. It's autogenerated by default. If you want multiple OIDC plugin instances to share the same cache, set it to any value, for example `wysiwyg` or the name of a realm, for example `my-realm`.
